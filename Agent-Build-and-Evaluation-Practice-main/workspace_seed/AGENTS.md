# Agent Memory

이 파일은 에이전트가 사용자에 대해 학습한 내용을 기록하는 장기 메모리다.
(선호, 반복되는 피드백, 역할 정의, 도구 사용에 필요한 정보 등)

## User
- PLC(Siemens) 엔지니어. TIA Portal 기반 프로젝트 진행.

## Preferences
- I/O List 추출 시 needs_review 항목을 항상 먼저 요약해서 보여줄 것.
- 생성/제안된 산출물은 사람 승인 전까지 확정된 것으로 취급하지 말 것.

## Notes
- 안전 규칙: 자동 생성된 로직에 필수 안전 인터록·비상정지가 있는지 항상 확인.
- 민감한 고객 사양/도면은 외부 LLM 처리 전 민감정보 포함 여부를 먼저 확인.
- TIA Portal Openness API/PLCSIM 은 이 에이전트가 직접 접근할 수 없음(별도 Windows
  워커 연동 전까지는 "할 수 있는 척"하지 말고 한계를 정직하게 알릴 것).
